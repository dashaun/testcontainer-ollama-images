# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/dashaun/testcontainer-ollama-images/security/advisories/new).
Include the affected version, impact, reproduction steps, and any known mitigations.

The maintainers will acknowledge a report as soon as practical, investigate it, and coordinate
disclosure and remediation with the reporter. Please allow time for a fix to be prepared before
publishing details.

## Supported Versions

Security fixes are applied to images built from the latest supported Ollama release and to the
latest development version of this repository.
